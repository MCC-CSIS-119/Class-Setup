# BASH Script Assignment

## Set up

Clone this repo to the Linux server and run `setup.sh`

### setup.sh

- Configures syntax highlighting for nano for each user
- Copies system_monitor_starter.sh to each student dir and makes it executable
- Creates the assignment self grader (`system_monitor_selfcheck.sh`) so students can check their progress

## Graders

### grade_system_monitor.sh

Run as root to grade all student's work

### grade_system_monitor.sh

Configured so each student can check their own grade
